# Nothing AI — Non's Universe

A responsive, single-page fictional AI brand website for an English class project.

## Run locally

Open `index.html` in a browser. No build step or dependencies required.

## Deploy

This is a static site. In Cloudflare Pages, connect this repository and use:

- **Build command:** leave blank
- **Build output directory:** `/`
- **Root directory:** `/`

The site uses Google Fonts when online and otherwise falls back to system fonts. Subscription links are illustrative mailto links for the school project; no checkout or real payment processing is connected.
